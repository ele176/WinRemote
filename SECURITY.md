# Security Policy

WinRemote is remote-control software, so security issues matter.

## Supported Versions

The `main` branch is the only supported development line while the project is in MVP status.

## Reporting a Vulnerability

Please avoid posting exploitable details in public issues. Use GitHub private vulnerability reporting if the repository enables it, or contact the maintainers through the repository's published security contact.

Useful reports include:

- Affected commit or release
- Steps to reproduce
- Expected and actual behavior
- Impact and likely attacker model
- Suggested mitigation, if known

## Non-Goals

WinRemote will not support stealth operation, credential theft, unauthorized access, Windows lock-screen bypass, UAC secure-desktop bypass, or persistence designed to evade user awareness.
